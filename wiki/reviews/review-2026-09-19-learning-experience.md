# 学习闭环的 UI / UX 深度审查

结论：本轮改动范围可交付；课程稳定链接、时长精度与模型评分仍是后续产品问题。没有宣称全产品已经达到最优。

本轮以职业学习者“回来继续一课 → 阅读中提问 → 测验 → 保存并继续”为主任务。
改动范围：路径页、阅读/测验切换、导师草稿、完成与画像更新。不是把测试通过当作全产品已经最优。
未新增依赖、账号、遥测、服务端存储或模型 prompt。

## 发现与修复

严重度：0 阻断，1 严重，2 中等，3 轻微，4 润色。

| 视角 | 具体发现 | 严重度 | 改动 |
|---|---|---:|---|
| 任务与信息架构 | 路径只重述摘要，不展示目标水平；继续入口不区分已读、测验草稿、已交卷 | 1 | 当前课内容/目标分区，真实状态驱动动作，测验入口直达正确标签 |
| 视觉层级 | 当前课、路线内下一课和重排争夺注意，手机在继续动作之前先看到重排 | 2 | 当前课唯一实心主行动，重排移至完整路径旁；窄容器不显示重复行按钮 |
| 交互连续性 | 阅读中问导师需要回到页面入口、手工复制；失败时下一条草稿被旧问题覆盖 | 1 | 阅读工具常驻，选文引用追加到可编辑草稿，不自动发送；失败保留两条输入 |
| 无障碍 | 搜索快捷键可在另一弹窗上叠加；长目录、吸顶栏可能遮挡章节和焦点 | 2 | 模态期间不再叠开搜索；引用关闭后回到阅读入口；目录限高内部滚动，锚点留距 |
| 文案与标签 | “完成”看起来等于技能进步；测验未准备好仍提供“先测验”引导 | 1 | 明确活动完成/测验证据/技能估计；测验不可用时提供继续阅读或明确跳过 |
| 响应式 | 固定导师缩小内容宽度；长选文动作与完整课程说明挤压小屏 | 2 | 按内容容器分栏；工具栏可换行；320px 触控长章节检查 |
| 感知性能 | 保存课程依赖十秒级 profile 请求，慢请求使“完成”一直等待 | 1 | 原子保存本地事实，独立显示评估状态，可立即继续或离开 |
| 信任与恢复 | 请求失败导致完成无法落地；重试和迟到结果可能重复记时或覆盖更新 | 1 | 可导出恢复任务、每目标串行、任务 ID 定位、旧画像结果防覆盖、无答案不伪造掌握度 |

## 三次迭代

1. **学习闭环先成立**：把完成事实从模型请求中拆出。验证失败、恢复、重复点击、无答案和并发更新。
2. **让下一步说得清楚**：路径主行动根据实际存档变化；目标水平首次进入路径与课程视图；阅读和导师关联。
3. **按截图和边界再修**：移动重排位置，移除已交卷动作旁无关的阅读时长，降低重复行动权重；
   补长目录内部滚动、窄屏选文工具两行布局、缺失测验的返回路径、导师新草稿防覆盖。320px 真触控截图发现三行工具栏，调整后加高度回归断言。

## 参考依据及取舍

- [Khan Academy：Course and Unit Mastery](https://support.khanacademy.org/hc/en-us/articles/115002552631-What-are-Course-and-Unit-Mastery)：
  技能水平由练习表现更新。这里采用“活动完成与掌握证据分开”的原则，不引入积分或儿童化奖励。
- [Duolingo：Review Previous Lessons](https://blog.duolingo.com/how-to-review-lessons-on-duolingo/)：
  既有明确继续路线，也允许重访。这里保留所有课程可访问，不把顺序建议变成强制锁定。
- [W3C：Status Messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：
  长请求与保存结果应能被辅助技术感知，且不抢焦点；保存/评估提示使用 status，不弹模态要求等待。

## 发布检查（仅本次改动范围）

| 检查 | 结论 | 证据 |
|---|---|---|
| 1 主任务清晰 | PASS | 当前课标题、真实状态与单一继续动作成组；桌面/手机人工看图。3 秒可理解是设计审查判断，未冒充用户实验。 |
| 2 主行动突出 | PASS | 当前课实心按钮，重排与路线行行动降级；阅读结束先测验、交卷后突出完成。 |
| 3 状态完整 | PASS | 未开始/已备好/阅读中/测验草稿/答案已保存/完成，以及评估 pending/failed/retry。 |
| 4 对比度 | PASS | 沿用已校验语义色，两主题 axe 检查；无新硬编码颜色。 |
| 5 焦点可见 | PASS | 搜索与引用关闭回焦点，阻止模态叠开，章节锚点避开工具栏。 |
| 6 错误可恢复 | PASS | 断网后完成、答案、时间均保留；刷新后可重试；输入草稿不丢。 |
| 7 手机可用 | PASS | 窄屏单列、长内容换行；触控目录内部滚动；双主题截图与溢出断言。 |
| 8 无模板化装饰 | PASS | 课程目标与实际记录构成界面，不增加渐变、勋章或虚构图表。 |
| 9 不误导/不强迫 | PASS | 可跳过测验但不伪造技能提升；引用不自动发消息；不以完成课数冒充掌握率。 |
| 10 动作有反馈 | PASS | 完成立即有本地反馈；慢评估允许离开；失败有持久提示与重试。 |
| 11 触控目标 | PASS | 触控按钮和测验标签最小 44px；目录链接增加触控间距；320px 专项断言。 |
| 12 标签诚实 | PASS | 继续阅读、继续测验、查看答案并完成对应实际状态；目标水平明确不是掌握声明。 |

## 尚不能宣称解决的产品问题

- 课程仍使用索引 URL，跨目标书签缺少稳定课程身份；已有 backlog F05，不能把重排数据安全当作稳定链接已完成。
- 时间统计由访问时间戳估算，长时间离开与后台停留不够精确；没有伪造更精确的时长。
- 模型整体进度存在波动；本轮明确分开“课程完成”与“技能估计”，没有重新定义模型评分。
- 自动化和人工看图不能替代真实学习者任务测试；没有把这次审查写成整体产品“极致”的证明。
